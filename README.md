# coderhouse-data-analytics

Proyecto del curso de Data Analytics.

## Módulo 4 — Entregable 3

[`modulo_4/ventas_tech_db.sql`](modulo_4/ventas_tech_db.sql) crea y carga
`Ventas_Tech_DB` en SQL Server: 4 categorías, 5 clientes, 6 productos y 10 ventas.

El repositorio incluye un Codespace con SQL Server 2022 y una prueba automática
que ejecuta el script dos veces y verifica los datos de ambas ejecuciones.
